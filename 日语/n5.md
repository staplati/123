## 一、和语

### 1. 词根：`あ-`（远称指示词根）
* **词根简介**：日语「こそあど」指示词体系中的远称词根（古形为 `か-` / `あ-`），指代距离说话人与听话人双方均较远的事物、场所、方向或人物，并进一步引申出人称代词及表示犹豫、惊讶的感叹词。

| 单词 | 声调 | 读音 | 词义 |
| :--- | :--- | :--- | :--- |
| ああ | ⓪ | ああ | 那样，那么 |
| あそこ | ⓪ | あそこ | （指代远处）那里；（指代自己和对方都知道的地方）那里 |
| あちら | ⓪ | あちら | （远处）那边；那个人，那位 |
| あっち | ③ | あっち | 那边；那个人 |
| あなた | ② | あなた | 你 |
| あの | ⓪ | あの | （指代远处事物）那个；（指代自己和对方都知道的事物）那个 |
| あのう | ⓪ | あのう | （带着顾虑和犹豫的心情呼唤对方）不好意思，那个…… |
| あれ | ⓪ | あれ | （表示离双方都有距离的）那个；（指之前发生过的，你和对方都熟悉的事情）那时 |
| あれ | ⓪ | あれ | （表示惊讶、奇怪）哎呀，哎哟 |
| あんな | ⓪ | あんな | 那样；那种 |

### 2. 词根：`あ-`（存在词根）
* **词根简介**：表示事物、植物或抽象状态“存在、拥有”的ラ行变格动词词根（`あり / ある`）。惯用寒暄语「ありがとう」由其连用形 `あり` 加形容词「難し（かたし）」的ウ音便构成，原意为“难得、稀有”。

| 单词 | 声调 | 读音 | 词义 |
| :--- | :--- | :--- | :--- |
| ありがとう | ② | ありがとう | 谢谢 |
| ある | ① | ある | （物品、植物等）在，有；有；发生；处于某种状态 |

### 3. 词根：`あか- / あけ / あかる-`（光明·红色词根）
* **词根简介**：古日语中表示“天色破晓、光线显现”的词根，由此分化出色彩词“赤（红）”以及表示光线充足、心情开朗的形容词“明るい”。

| 单词 | 声调 | 读音 | 词义 |
| :--- | :--- | :--- | :--- |
| 赤 | ① | あか | 红色；完全 |
| 赤い | ⓪ | あかい | 红色的 |
| 明るい | ⓪③ | あかるい | 明亮的；快活的 |

### 4. 词根：`あさ / あす / あした`（清晨·次日时间词根）
* **词根简介**：表示“黎明、早晨”并向时间轴后方延伸为“明天、后天”的同源时间词根。「今朝（けさ）」由指示词「この」与「あさ」缩约音便而成；「あさって」由「あす」与「さって」复合演化而来。

| 单词 | 声调 | 读音 | 词义 |
| :--- | :--- | :--- | :--- |
| 朝 | ① | あさ | 早晨，早上 |
| あさって | ② | あさって | 后天 |
| 明日 | ③⓪ | あした | 明天 |
| 今朝 | ① | けさ | 今天早上 |

### 5. 词根：`あつ-`（暑热词根）
* **词根简介**：表示气温炎热或物体温度高的形容词词根（`あつ-` + 形容词词尾 `-い`）。

| 单词 | 声调 | 读音 | 词义 |
| :--- | :--- | :--- | :--- |
| 暑い | ② | あつい | （天气）热的 |
| 熱い | ② | あつい | 热的，烫的 |

### 6. 词根：`あと`（后续·余留词根）
* **词根简介**：表示空间上的“后方”、时间上的“之后”以及数量上的“剩余、另外”的词根。

| 单词 | 声调 | 读音 | 词义 |
| :--- | :--- | :--- | :--- |
| 後 | ① | あと | 后面；之后 |

### 7. 词根：`あに / あね`（兄姐亲属词根）
* **词根简介**：表示年长同胞兄长的词根 `あに` 与年长同胞姐妹的词根 `あね`；加上美化接头词「お」和敬称后缀「さん」后发生元音同化，形成对他人兄姐或年轻男女的敬称。

| 单词 | 声调 | 读音 | 词义 |

| お姉さん | ② | おねえさん | 姐姐；对年轻女子的称呼 |

### 8. 词根：`い-（入）`（进入词根）
* **词根简介**：表示“由外向内进入、容纳”的动词词根。「入る（はいる）」由「這ひ入る（はひいる）」演变而来，其核心词根仍为 `い-`；「入れる（いれる）」为其对应的他动词。

| 单词 | 声调 | 读音 | 词义 |

### 9. 词根：`い- / いらっしゃ-`（在·往来敬语词根）
* **词根简介**：表示有生命体（人或动物）“存在、停留”的词根 `い-`，其尊敬语派生出表示“在、来、去”的特殊ラ行五段动词 `いらっしゃる` 及服务行业寒暄语 `いらっしゃいませ`。

| いる | ⓪ | いる | （人、动物等）在，有 |

### 11. 词根：`いそ-`（急忙词根）

### 12. 词根：`いつ-（何时）`（时间疑问词根）
* **词根简介**：针对时间点进行询问的固有疑问词根，后接副助词「か」「でも」「も」后分别转化为不确定时间、全称肯定与高频时间副词。

### 15. 词根：`うえ / うわ- / あが- / あげ-`（上方·上升词根）
* **词根简介**：表示空间“上方”及“由下向上移动”的同源词根群。名词独立形为「うえ」，复合前接形为「うわ-」（如「上着」）；自他动词词根为 `あが-` / `あげ-`（授受动词「あげる」源于“向上呈献”）。

| 上着 | ⓪ | うわぎ | 外套；上衣 |
